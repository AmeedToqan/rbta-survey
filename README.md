# رَبطة — Web Survey

## التشغيل المباشر
1. ثبّت Node.js.
2. افتح Terminal داخل مجلد المشروع.
3. نفّذ:
   npm install
   npm start
4. افتح:
   http://localhost:3000

## لوحة الإدارة
افتح:
http://localhost:3000/admin

مفتاح الإدارة الافتراضي:
rbta-admin

يفضل تغييره قبل النشر عبر متغير البيئة:
ADMIN_KEY=كلمة_سر_قوية npm start

## ملاحظات
- الردود تحفظ محليًا في responses.json.
- رابط Instagram مضاف.
- روابط iOS وAndroid متروكة كـ placeholders حتى يتم تزويدي بالروابط الصحيحة.
- لتشغيله أونلاين يجب رفع المشروع على استضافة Node.js أو منصة تدعم Node/Express.
